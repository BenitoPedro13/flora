# Flora Frontend ⚛️

Next.js 16 Web Application for visualizing satellite data.

## Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: TailwindCSS v4
- **Maps**: React Leaflet

## Development

```bash
pnpm dev
```

Runs on [http://localhost:3000](http://localhost:3000).
